# Session Reference: app-flutter-template v0.4.1 P0 Fixes

Flutter 3.44.8 toolchain reference: AGP 9.0.1, KGP 2.3.20, Gradle 9.1.0.
This session fixed P0 blockers discovered by the v0.3.x read-only audit.

## Fresh checkout survival

A clean `git archive HEAD` checkout MUST pass:
1. `flutter pub get` — resolves 113+ deps
2. `dart run build_runner build --delete-conflicting-outputs` — regenerates `*.g.dart`/`*.freezed.dart`
3. `dart format --set-exit-if-changed lib/ test/` — do NOT run on `.` (polluted by `build/`)
4. `flutter analyze lib/` — exit 0; exit code changes to 1 when stdout is redirected
5. `flutter test` — 73/73

## CI order (fixing a template with ignored generated files)

```
flutter pub get
dart run build_runner build --delete-conflicting-outputs
dart format --set-exit-if-changed lib/ test/
flutter analyze lib/
flutter test --coverage
```

Build_runner BEFORE format/analyze/test, not after.

## Known quirks

- `flutter analyze lib/ > /dev/null 2>&1` exits 1; without redirect exits 0. Terminal detection bug in the tool.
- `dart format .` formats `build/` directory artifacts. Only use `lib/ test/` as scope.
- `flutter create` in Flutter 3.44 generates Kotlin DSL (`.kts`), not Groovy DSL (`.gradle`). If migrating Groovy files, keep `.gradle` format but use new DSL syntax (`= ` assignment style).
- Post-increment `((P++))` returns 0 in bash/MSYS when P is 0; use `((++P))` for safe verification scripts.
