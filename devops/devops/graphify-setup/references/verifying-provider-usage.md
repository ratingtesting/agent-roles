# Верификация: запросы «не видны» в статистике провайдера

Когда пользователь спрашивает «почему я не вижу обращения к моделям в
статистике 9router? Ты реально делал тесты?» — это вопрос ПРОВЕРЯЙ, а не
уверяй. Тесты, которые реально шли, могут не попадать в агрегатную
статистику дашборда.

## 9router: requestDetails vs usageHistory
6router хранит запросы в `C:\Users\Unicorn\AppData\Roaming\9router\db\data.sqlite`:

- Таблица **`requestDetails`** — КАЖДЫЙ запрос, с временной меткой и полем
  `success/error`. Это лог всего, что реально прошло.
- Таблица **`usageHistory`** — агрегат для дашборда, пишется ТОЛЬКО для
  запросов с `connectionId` (настроенное подключение провайдера).
- Бесплатные `oc/*`-модели: `connectionId = NULL`, `cost = 0` → попадают в
  `requestDetailshead,но НЕ заносятся в `usageHistory`. Поэтому в статистике
  `oc/deepseek-v4-flash-free`, `oc/nemotron-3-ultra-free`,
  `oc/laguna-s-2.1-free` их НЕТ — и не только от ваших тестов, а всегда.

**Если в дашборде пусто по `oc/*` — это не значит, что тестов не было.**
Доказательство — `SELECT * FROM requestDetails WHERE ts > <время>`.

## 9router /v1/models висит в таймаут
`GET http://127.0.0.1:20128/v1/models` НЕ отвечает (15–40s → timeout), хотя
`POST /v1/chat/completions` работает нормально. Это квирк, не баг: список
моделей бери из `config.yaml` профиля / `auth.json` / у пользователя, а не
с эндпоинта. Nous-портал на `/v1/models` отвечает нормально (354 модели),
id вида `stepfun/step-3.7-flash:free`, `tencent/hy3:free`.

## Пайплайн теста модели (чтобы данные были доказуемыми)
1. Не доверяй латентности одного пинга — задачу и количество влияет.
2. Гони реальную извлекательную задачу (graphify extraction) при
   `temperature=0`, ≥3 повтора; проверяй JSON, полноту сущностей,
   стабильность.
3. Сверяй с логами провайдера (см. выше), а не только со своим выводом.
4. Сохраняй сырой результат прогона (стенограмма/вывод) — при
   «ты правда делал?» предъявляешь записи, а не пересказ.

## MSYS-пути к БД sqlite
Пути Windows через python `os.path.expanduser("~/AppData/Roaming/9router/...")`
работают; не передавай `/c/...` пути в Windows-бинарь (сдвоит `C:\c\`).
